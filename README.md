# Starfounding Knightwander

Open-source Godot 2D fantasy action-platformer development workspace.

## Source-of-truth policy

This repository is the durable cross-chat handoff point. A ChatGPT transcript, screenshot, or previously generated archive is **not** a GitHub commit. Work is considered published only when its repository paths and Git commit can be verified.

## Current provenance

The locally verified **SK SCALE/ART S30** standalone QA prototype covers a 960×540 Godot test environment with four parallax layers, Profile A (Mega Man X4-inspired) key-pose transitions, dedicated standing/crouching textures, input-driven traversal, horizontal camera look-ahead and experimental vertical jump framing. **It is not the original full playable game.**

The original Starfounding Knightwander project, approved production sprites, and integration acceptance remain separate and unverified. Dead Cells is a secondary animation/atmosphere reference; Yoshi/Kirby/Tales of Phantasia are bracketed out of the current SCALE/ART grading.

## Archive integrity

See `provenance/S30_SOURCE_MANIFEST.md` for the local S30 package’s SHA-256 fingerprint and verified-scope boundary. Do not claim original-game restoration or complete source backup from documentation alone.
